# Final Project - Emotion Detector

An AI-based web application that analyzes emotions from textual inputs using the Watson NLP library and deployed as a web application using Flask.

## Features
- Detects five core emotions: anger, disgust, fear, joy, and sadness.
- Identifies the dominant emotion.
- Packaged as a reusable Python package `EmotionDetection`.
- Unit-tested using Python's `unittest` framework.
- Deployed with a user-friendly Flask web interface.
- Complete with robust error handling for invalid or blank inputs.
- Validated with static code analysis using `pylint`.
